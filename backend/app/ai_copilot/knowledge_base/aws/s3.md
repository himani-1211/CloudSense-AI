title: Amazon S3 (Simple Storage Service)
provider: aws
category: storage
---

Amazon S3 (Simple Storage Service) is AWS's object storage service. Data is stored as objects
inside buckets, with virtually unlimited capacity and 11 nines of durability.

Common use cases: file storage, static website hosting, backups, data lakes, images, videos, and
log storage.

To create a bucket: open the S3 console, click "Create bucket", choose a globally unique bucket
name, select a region, configure permissions (block public access is on by default), and create
the bucket.

Best practices:
- Keep "Block Public Access" enabled unless the bucket is intentionally public (e.g. a static
  website).
- Enable versioning on buckets holding important data to protect against accidental deletion.
- Use lifecycle rules to transition infrequently accessed objects to cheaper storage classes
  (Standard-IA, Glacier) or expire them.
- Enable server-side encryption (SSE-S3 or SSE-KMS) for data at rest.
- Use bucket policies and IAM scoped to least privilege rather than broad wildcard access.
